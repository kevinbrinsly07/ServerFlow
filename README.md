# ServerFlow 🚀

[ServerFlow](https://github.com/kevinbrinsly07/ServerFlow) is a modern full-stack application featuring a robust C# / .NET backend and a dynamic TypeScript frontend, containerized for seamless deployment using Docker.

## 🛠️ Tech Stack

* **Backend:** C# / .NET
* **Frontend:** TypeScript
* **Testing:** xUnit (`tests/ServeFlow.UnitTests`)
* **Infrastructure:** Docker / Docker Compose

## 📁 Project Structure

* `backend/` - Core server-side application logic and APIs.
* `frontend/` - Client-side interface.
* `tests/` - Unit and integration tests.
* `docker-compose.yml` - Multi-container orchestration setup.
